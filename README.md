# Garda
Garda adalah sistem manajemen PKL/Magang mahasiswa yang fokus pada otomatisasi administrasi. Dibuat dengan PHP dan JavaScript untuk membantu mahasiswa mendokumentasikan kegiatan harian (logbook) secara digital dan menghasilkan laporan akhir secara otomatis, sehingga mengurangi beban administratif di akhir masa praktik.
